# Копейка («Расчетки»)

Программа сотрудника АО «АВТОВАЗ»: собирает расчетки из почты — скачивает PDF-расчетки
из указанной папки или автоматически из всех папок ящика, показывает начисления
за все месяца.

**Платформы:** Windows + Android (Kivy/KivyMD).

## Структура

- `main.py` — интерфейс и логика
- `pdf_parser.py` — разбор PDF-расчеток
- `storage.py` — настройки и база (ПК: папка пользователя; Android: папка приложения)
- `main.spec` — сборка exe (PyInstaller), имя сборки Kopeyka
- `buildozer.spec` — сборка APK
- `icon.png`, `presplash.png`, `kopeyka.ico` — иконка и заставка для APK
- `.github/workflows/android.yml` — сборка APK (GitHub Actions)
- `ИНСТРУКЦИЯ.md` — руководство пользователя
- `imap_lastcheck.json`, `imap_senders.json` — служебные файлы ускорения проверок
  (создаются при работе, в `.gitignore`)

## Сборка Windows

    pip install -r requirements.txt
    pyinstaller main.spec

Результат: `dist/Kopeyka/` (Kopeyka.exe + `_internal`) → запаковать в zip.

Данные лежат не рядом с exe, а в «Документы/Расчетки» — папку программы можно
переносить куда угодно.

## Сборка Android

Только через GitHub Actions: **Actions → Build Android APK → Run workflow**.

- Ветка `android-test` — тестовая сборка: имя «Копейка тест», обновления с пререлизов.
- Ветка `main` — релизная сборка: имя «Копейка», обновления с релизов.
- Запуск с тега (Tags → v1.0.x) — APK автоматически прикрепляется к релизу GitHub.
- Запуск с ветки — APK в артефакте `app-debug`, к релизу прикрепляется вручную.

Подпись: секрет `DEBUG_KEYSTORE_B64`. **НЕ перегенерировать ключ** — иначе обновления
перестанут ставиться поверх.

Кэш сборки: ключ `buildozer-ubuntu-v1` (`~/.buildozer` с SDK/NDK); первый прогон после
сброса кэша долгий (около получаса). В workflow есть симлинк `tools → cmdline-tools/latest` —
правка пути sdkmanager для свежего SDK, не убирать.

## Возможности

- Несколько почтовых ящиков, автопроверка 1–5 числа.
- Сам находит папку расчеток: по всему ящику или только в указанной папке.
- Снятие пароля PDF и разбор: получка, начисления, удержания, коды
  (включая «П» — перерасчет за прошлый месяц).
- Поиск по кодам АВТОВАЗ: подробная информация по месяцам и история начислений с группировкой по годам.
- Статистика за год и за весь период: НДФЛ, аванс, больничные, «Подробнее» за год.
- Обрыв связи посреди проверки — не ошибка: автопереподключение и докачивание недостающего.
- «О программе», проверка обновлений с GitHub (релизный и тестовый каналы).
- Быстрые повторные проверки: только письма с даты последней проверки и от известных
  отправителей, выборка пачками по 400 UID.
- Пароли хранятся локально и наружу не передаются.

## Известные особенности

- **NVIDIA:** если окно мерцает при перетаскивании — в панели NVIDIA оставить G-SYNC
  только для полноэкранного режима (убрать «и в окне»).

## История версий

### 1.0.6

Добавлено:

- Статистика за год: НДФЛ, аванс, больничные; «Подробнее» за год с кликабельными строками и блоком дополнительных начислений.
- Статистика за весь период: суммарные цифры по всем годам работы.
- Автопереподключение при обрыве связи посреди проверки (до 2 попыток) с докачиванием недостающего вместо ошибки и частичной загрузки.
- Отправка лога с телефона через mailto: почтовый клиент с предзаполненным письмом.
- Автопроверка обновлений раз в день с учётом сети и диалогом подтверждения; ручная проверка через «О программе» осталась.
- Пошаговая подсказка на пустом главном экране для первого запуска.

Изменено:

- Плитки кодов переделаны: тап по коду в расчетке открывает подробную информацию по месяцам — историю начислений кода с группировкой по годам, доведённой прокруткой и читаемым шрифтом; описание кода во всех окнах истории.
- Справочник кодов АВТОВАЗ переделан в поиск по кодам: введите код — получите все месяца и суммы, где он начислялся.
- Опечатка или отсутствие папки на сервере: вместо подсказки в журнале — окно «Проблема с папкой» со списком реальных корневых папок и кнопками «Искать во всех папках», «Открыть настройки», «Отмена»; список прокручивается, кнопки видны всегда.
- Адаптив колонок «Получка»/«ЗП» на узких экранах (порог 340dp).

Исправлено:

- Дубли PDF в Downloads при повторных проверках и перескачивании (включая файлы с (2), (3) в имени).
- Пустое поле папки: восстановлен надёжный обход всех папок ящика; при первом запуске с указанной папкой — полный скан.
- Отработанные часы доп-расчеток равны индивидуальному фонду времени (код 099).
- Кнопка PDF открывает файл по правильному пути Downloads; кнопка «Закрыть» работает в окнах истории.
- Диалоги на узких экранах и в низком окне: текст переносится по ширине, не вылезает за края и не перекрывает заголовок.

### 1.0.5

Добавлено:

- Обход всех папок ящика с поддержкой UTF-7: кириллические имена папок читаются корректно.
- Предфильтр BODYSTRUCTURE: скачиваются только письма с расчетками, почтовый мусор не качается.
- Раздельный счетчик обычных и доп-расчеток в шапке: «23 шт. +2 шт. Доп. с октября 2024».
- Имя файла по содержимому: бюджетные доп-расчетки (код 099) сохраняются с суффиксом _DOP.
- Кнопка PDF: вызов просмотра оригинального файла расчетки из приложения.
- Дефолтное поведение: папку можно не указывать — приложение само находит расчетки во всех папках ящика.

### 1.0.4

Изменено:

- Унификация поиска папки расчеток: пустое поле — обход всех папок ящика (Яндекс
  и прочие) или «Вся почта» (Gmail); указанное поле — быстрый поиск только в ней.
- Опечатка в имени папки: подсказка со списком реальных папок сервера; вложенные
  папки указываются полным путём с разделителем сервера (`|` у Яндекса, `/` у Gmail).
- Первый запуск с указанной папкой без писем: совет проверить имя папки и правила
  фильтрации или оставить поле пустым. Повторная проверка без нового: «Новых писем нет.»
- Парсер списка папок IMAP: работает с любым разделителем сервера.
- Ускорение проверок: поиск писем с даты последней проверки (SINCE) и от запомненных
  отправителей (FROM), выборка пачками по 400 UID.
- Релизная сборка называется «Копейка», тестовая — «Копейка тест» с отдельным каналом обновлений.

### 1.0.3

- Мелкие правки: уточнены тексты и ссылки инструкции, заменены символы, отображавшиеся
  на Android квадратиками. Увеличен шрифт в некоторых окнах, добавлено выравнивание
