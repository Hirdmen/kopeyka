# Копейка — сборщик расчетных листков

Программа сотрудника АО «АВТОВАЗ»: сама качает расчетки с почты,
снимает пароль с PDF, разбирает цифры и показывает крупно и понятно.

## Возможности
- Несколько почтовых ящиков, автопроверка 1–5 числа
- Снятие пароля PDF и разбор: получка, начисления, удержания, коды
- Справочник 128 кодов АВТОВАЗ с поиском и карточкой кода
- «О программе», проверка обновлений с GitHub.
- Пароли хранятся локально и наружу не передаются

## Запуск на ПК
1. Python 3.10+
2. `pip install kivy kivymd pypdf`
3. `python main.py` (или `pythonw main.py` — без консоли)
