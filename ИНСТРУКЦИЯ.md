## Установка

**Windows:** скачать `Kopeyka-1.0.5-windows.zip`, распаковать в папку
(например, `C:\Kopeyka`), запустить `Kopeyka.exe`.
Из архива без распаковки не запускать!

**Android:** скачать APK и установить.
Обновления ставятся поверх, настройки и база сохраняются.

## Настройка почты: нужен ПАРОЛЬ ПРИЛОЖЕНИЯ

В поле пароля вставляется НЕ обычный пароль от почты, а специальный
«пароль приложения» (он показывается один раз — сразу копируй).

### Яндекс

1. Включи IMAP: Почта → Настройки → Все настройки → «Почтовые программы» →
   включить IMAP.
2. Создай пароль приложения: https://id.yandex.ru/security →
   «Пароли приложений» → создать → выбрать «Почта».
3. Скопируй выданные 16 символов — это и есть пароль для приложения.

### Google (Gmail)

1. Включи двухэтапную аутентификацию (если выключена).
2. Включи IMAP: Gmail → Настройки → «Пересылка и POP/IMAP» → «Включить IMAP».
3. Создай пароль приложения: https://myaccount.google.com/apppasswords →
   название любое (например, «Копейка») → получишь 16 символов — вставь их в приложение.

## Папка расчеток: не обязательна, но ускоряет проверку

С версии 1.0.4 приложение находит расчетки само: если поле «Папка» в настройках пустое,
Яндекс-почта обходится по всем папкам, Gmail смотрит во «Всей почте».
Настраивать ничего не нужно.

Для ускорения проверок можно складывать расчетки отдельно:

1. Создай в почте папку «Расчетки».
2. Создай правило: если письмо от persmaster@vaz.ru → перемещать в «Расчетки».
3. Укажи имя папки в настройках приложения: `Расчетки`.

### Если с папкой что-то не так

- **Опечатка в имени:** приложение покажет список реальных папок твоего ящика —
  скопируй нужное имя из подсказки.
- **Вложенные папки** указываются полным путём с разделителем сервера:
  у Яндекса это `|` (пример: `БИРЖИ|C-CEX.com`), у Gmail `/` (пример: `[Gmail]/Вся почта`).
- **Папка указана, база ещё пустая, а писем в ней нет:** приложение посоветует проверить
  имя папки и правила фильтрации или оставить поле пустым — тогда поиск пойдет по всей почте.

## Кнопка «Проверить»

«Проверить» — ищет только новые письма с момента прошлой проверки.
Надпись «Новых писем нет.» означает, что новых расчеток в почте не появилось — это нормально.

При первом запуске нажми «Проверить» несколько раз: приложение пройдёт
по истории почты и соберёт все старые расчетки в базу.

## Интерфейс (версия 1.0.5)

### Главный экран

Сверху — плитка со счётчиком обработанных расчеток, ниже — одна большая
кнопка «Проверить», ещё ниже — журнал последней сессии. Тап по заголовку
«Журнал (N)» сворачивает или разворачивает список событий.

### Меню

Кнопка «≡» в шапке главного экрана. Три блока:
- **Основное** — настройки почты, встроенная инструкция.
- **Информация** — справочник кодов, о программе.
- **Сервис** — перескачать расчетки заново, журнал сессии.

### Детализация расчетки

При тапе по строке расчетки открывается её содержимое: часы, средние
и начисленная сумма, список начислений и удержаний с кодами. Справа
в шапке — круглая кнопка «PDF», открывает оригинал расчётки во
внешнем просмотрщике.

На Android копия PDF дополнительно сохраняется в папку `Загрузки/Kopeyka`
и доступна через любой файловый менеджер.

### Настройки

Экран-хаб с тремя блоками:
- **Оформление** — три цветовые схемы (тёмная, светлая зелёная, светлая синяя).
  Применяются при следующем запуске приложения.
- **Обновления** — тумблер автопроверки обновлений при старте.
- **Почта** — отдельный экран со списком почтовых ящиков.

### О программе

Блоки «Поддержка» (перевод через СБП по номеру телефона — тап по кнопке
копирует номер в буфер) и «Связь» (почта разработчика, сообщество
ВКонтакте, проект на GitHub).

## Возможности

- Несколько почтовых ящиков, автопроверка при запуске.
- Снятие пароля PDF и разбор: получка, начисления, удержания, коды,
  включая коды с буквой «П» (перерасчет за прошлый месяц).
- Справочник 128 кодов АВТОВАЗ с поиском и карточкой кода; тап по коду
  внутри расчетки открывает его карточку.
- Три цветовые схемы оформления с применением при перезапуске.
- Просмотр PDF расчёток одной кнопкой + копии в «Загрузки/Kopeyka» на Android.
- Пароли хранятся локально и наружу не передаются.

## Обновления

При включенном тумблере (Настройки → Обновления) приложение проверяет
новую версию при запуске и предлагает скачать. Можно обновить вручную:
Меню → «О программе» → «Проверить обновления». Релизная «Копейка»
обновляется с релизов, тестовая «Копейка тест» — с пререлизов.

## Где лежат файлы и настройки

Все данные программы хранятся отдельно от самого приложения, поэтому
при обновлении настройки и база не теряются.

- **На ПК:** папка «Документы» → «Расчетки» (например, `C:\Users\Имя\Documents\Расчетки`).
  Там лежат база данных (`salary.db`), настройки (`config.json`) и скачанные PDF
  (в подпапках с именем вашей почты).
- **На Android:** во внутренней памяти приложения. Скачанные PDF просматриваются
  прямо в программе, копии лежат в «Загрузки/Kopeyka».

Рядом с программой создаются служебные файлы `imap_lastcheck.json` (дата последней
проверки) и `imap_senders.json` (запомненные отправители расчеток). Они ускоряют
проверки; удалишь их — следующая проверка просто пройдет по всей почте заново.
